# 海克斯方块乱斗：移动端实时 1v1 设计规格

## 目标

构建一个竖屏手机优先、服务器权威的实时 1v1 俄罗斯方块对战原型，为后续抖音小游戏客户端迁移提供可验证的网络和玩法基础。

## 核心规则

- 双方同时落块，客户端本地预测，服务器校验并广播。
- 消行获得能量；技能从随机三选一中获得，最多携带 3 个。
- 技能使用有短暂攻击预警和反制窗口。
- 方块触顶、主动退出或连接超时导致失败。

## 架构

- `index.html` / `game.js`：当前浏览器玩法和移动端触控验证器。
- `server.js`：Node.js WebSocket 房间服务，负责匹配、房间状态和权威事件。
- 后续 Cocos 客户端通过同一事件协议替换浏览器验证器。

## 非目标

第一阶段不实现登录、支付、排行榜、广告、观战和复杂养成。

## 成功标准

- 两个设备可以通过邀请码进入同一房间。
- 操作、技能和房间状态能通过 WebSocket 双向传输。
- 断线后房间在保护时间内保留并可恢复。
- 手机竖屏触控区域不遮挡主棋盘。
